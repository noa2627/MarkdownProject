# Contribution Guidelines
Thank you for your interest in contributing to this project!

## Code Style
- Write clear and readable code.
- Use descriptive names for variables and functions.
- Keep the code organized and add comments when necessary.

## Pull Requests
- Create a separate branch for each new feature or fix.
- Write clear commit messages.
- Explain your changes when submitting a pull request.
- Make sure your changes have been tested.

## Reporting Issues
- Check existing issues before creating a new one.
- Describe the problem clearly.
- Include steps to reproduce the issue.
- Provide screenshots or error messages when relevant.
